# Private source access

This public repository is a concise product case study. MAYA's application source, internal
architecture, operational data, diagnostics, and development history are maintained privately.

## Interview review options

Depending on the role and review scope, technical discussion can use one of these formats:

1. **Guided product demonstration** — review the product experience and design decisions.
2. **Focused technical walkthrough** — discuss selected implementation patterns without
   distributing the complete source.
3. **Scoped code review** — inspect agreed modules or examples in a controlled setting.
4. **Time-bounded repository access** — available when appropriate for formal technical due
   diligence.

Access is arranged directly with a named reviewer and does not grant permission to redistribute,
mirror, or publish private material.
