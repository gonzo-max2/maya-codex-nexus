Aegis Principal Engineer / Product Creator · 2026-Present

Policy, provenance, and reversible execution for semantic agents.

  • Designed and implemented a local-first runtime between AI models and the operating system; deterministic code owns permissions, approvals, path confinement, process ownership, receipts, rollback data, and terminal completion.
  • Unified a prompt-toolkit/Rich CLI and React Studio over the same canonical runtime events and authority model.
  • Implemented persistent missions, checkpoints, cancellation, provider recovery, exact tool receipts, proof manifests, specialist routing, JIT skills, and workspace-scoped verified memory.
  • Hardened execution with process-group cleanup, output limits, optional Docker isolation, mandatory SSH host verification, secret redaction, and SSRF-aware web access.

Boundary: pre-production alpha for one operator on a trusted workstation; not presented as an independently audited multi-tenant security boundary.

NOVA Product Architect / Full-Stack AI Engineer · 2026-Present

Proof-carrying change control for machine-generated software.

Boundary: recorded checks are self-authored baseline evidence; hosted tenancy, RBAC, KMS/HSM custody, installed GitHub integration, and independent certification remain unfinished or absent.
